# Focused Finance overview and on-demand insights

Finance opens into a concise household overview instead of a pillar AI report. The overview uses the same selected checking/savings accounts and reconciled projection as Cash Forecast: cash anchor, month-end balance, and dated 30-day floor. Missing balances remain unavailable; verified zero remains zero. Source issues, projected shortfalls, earlier unmatched plans and unlinked bank activity have direct review destinations. The daily meeting entry opens the existing five-cadence meeting workspace; it does not invent a calendar appointment.

Cash Forecast retains a compact source qualification beside its title. Reconciliation figures, pending details, historical qualifications and forecast help are in a closed disclosure. Account/month controls and forecast interaction remain intact. Vendor sorting appears on relevant list screens. Recording and approval utilities sit in a Finance disclosure which opens while recording; archived recordings remain accessible. Repeated Finance workspace tabs give way to the overview destination cards, existing sidebar and Back navigation.

Other existing pillar analysis landing pages show navigation and optional Insights. They do not request pillar analysis until Insights is opened. Scheduled analysis, meeting report preparation, report edits, permissions, audit, Undo, bank refresh behavior and all financial calculation rules are preserved.

Validation: model coverage for shared anchor/floor, missing evidence, zero, leap-year boundaries and source exceptions; browser coverage for overview navigation, collapsed details, explicit insights, and pending-hold reconciliation on desktop, iPhone, portrait tablet and landscape tablet. Production build and bundle/source budgets checked. Full repository verification also runs in GitHub Actions.

Browser workflows pin Ubuntu 24.04 because the project's Playwright 1.55 browser dependencies do not support the newly selected Ubuntu 26.04 image. The persistent meeting utility stays mounted across page navigation so entering Finance cannot interrupt an active recording.

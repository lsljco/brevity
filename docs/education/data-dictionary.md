# Education data dictionary

- **Baseline**: pre-program assessment evidence; never counted as a completed tutoring encounter.
- **TutorSession**: one completed instructional session with assessor, date, responses, optional fluency probe, and curriculum provenance.
- **StudentResponse**: response-level evidence linked to one activity and one prerequisite/target skill; may additionally reference one or more official standards.
- **StudentSkillMastery**: derived RED/YELLOW/GREEN/BLUE status for a discrete skill.
- **StudentStandardProgress**: separately derived status for an official Grade 3 standard. Prerequisite evidence without a standard code cannot modify this collection.
- **RetrievalSchedule**: next evidence date for GREEN/BLUE spaced retrieval or near-term repair/confirmation.
- **ProgressCheck**: comparable periodic assessment; fluency comparisons require an explicit comparison group/probe identity.
